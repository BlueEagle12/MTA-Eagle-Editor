# Eagle Blender Authoring Add-on

Install `eagle_mta_toolkit` in Blender to author definition IDs, per-object TXD
assignments, element types, LOD settings, dimensions, interiors, and map
metadata. It does not generate resources or depend on DragonFF.

Drag the saved `.blend` into Eagle Editor to run the native map builder. Blender
evaluates the scene; Eagle owns slicing, DFF/TXD/IMG generation, and map output.
