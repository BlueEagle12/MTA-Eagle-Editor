# Changelog

## Unreleased — 2026-09-10

### What's Changed

- Added draggable dividers beside the side panels across the editor tabs, including Editing, Vehicles, and CULL, so users can adjust the space available to the viewport.
- Remembered panel widths separately for each tab during the editor session, including when switching tabs or temporarily hiding a browser on a smaller window.
- Kept the existing automatic sidebar hiding on small windows and added size limits to preserve usable viewport space.
- Adjusted controls in the lighting, LOD audit, vehicle, water, and CULL panels to fit narrower widths.
- Kept panel resizing separate from camera movement, scene selection, and existing scrollbar drags.
